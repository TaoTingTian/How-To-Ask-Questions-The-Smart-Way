## 2. 评价：做得好的地方

1. **信号严格滞后**（T-1 信号，T 日成交），没有未来函数；百分位只用当日及以前的数据。
2. **S 由三个相互独立的估值维度等权合成**，不做加权优化，本身不容易过拟合。
3. **真实资金流口径 + XIRR**，比"假设一次性全投"诚实得多。
4. 规则书已经意识到 MA60 是孤峰，主动牺牲点估计换稳健性，并写明"只有 3 个样本"。方向是对的。

## 3. 评价：主要问题（按严重程度排序）

### 3.1 【最严重】S 的"15 年百分位"在回测里实际只有 2–4 年历史，三次清仓可能都是数据起点造成的假象

数据从 2011-09 开始，所以 2015 年的"15 年百分位"只拿 **2011–2015 这段历史低估值期**作比较。2015-06 的沪深300 PB≈2.1、PE≈15.6，放在 2011–2015 里是极贵（S=4.7），但放在 2005–2015 里就不是：2007–2010 年 PB 长期在 2.5–7、PE 在 20–50。

由于拿不到 2005–2011 的数据，我做了解析压力测试：补入 N 个更早的交易日，其中比卖出日"更贵"的比例为 f，然后重算卖出日的 S：

| 卖出信号日 | 原 S | f=0.3 | f=0.5 | f=0.7 |
|---|---|---|---|---|
| 2015-06-26 | 4.7 | 20.9 | **33.7** | 46.5 |
| 2018-02-07 | 11.9 | 21.1 | **31.3** | 41.5 |
| 2021-03-08 | 11.0 | 18.2 | **25.7** | 33.2 |

按 2007 年大牛市的估值水平，f 大概率不低于 0.5，那么 **3 次卖出都不会触发（S 都不低于 25）**。另外两项检查也指向同一结论：
- 只要求百分位至少有 5 年历史（min_n=1260，从 2016-12 起），2018 年那次清仓就消失了，Plan C 的 XIRR 降到 8.67%（永不清仓 7.74%）
- 百分位窗口改成 3 年，卖出日期完全换了一组

**结论**：在补齐 2005 年起的数据前，规则书 §五 的成绩不能当作策略的真实能力。这条比参数选择更重要。

### 3.2 收益集中在单一事件上

| 只允许这次卖出 | 相对永不清仓的 XIRR 贡献 |
|---|---|
| 2015 | **+2.22pp** |
| 2017-18 | +0.73pp |
| 2020-21 | +1.25pp |

分段看：2013-11～2019 年 Plan C 22.97% vs 永不清仓 13.96%；**2020～2026 年 8.97% vs 8.68%，几乎没有优势**。后半段的回撤降低（-31% vs -42%）仍然有价值，但收益增强基本来自 2015 年那一次。

### 3.3 Plan C 落在自身参数邻域的前 14%，仍有选择偏差

在 225 组相邻参数（卖出阈值 20/25/30 × 恢复阈值 50/55/58/60/65 × 5 组均线 × 3 档 U）中，Plan C 的 12.28% 排在 **第 86 百分位**，邻域中位只有 **10.41%**。"在 9 格里选最平稳的一行"本身就是用回测结果挑参数，只是比挑最高点温和。
- 单均线扫描呈锯齿状：MA40 9.09%、MA50 10.07%、MA60 12.97%、MA70 11.77%、MA80 12.28%、MA100 12.79%、MA120 11.46%。三均线组合并没有消除这种锯齿：30/60/120 是 12.97%，40/80/160 是 12.28%，60/120/240 的 U≤1/3 是 11.46%。
- **没有趋势过滤（只看 S<25）时 XIRR 只有 8.36%**，几乎和永不清仓一样。也就是说，择时收益几乎全部来自"均线窗口恰好在 3 个顶部附近给出信号"。

### 3.4 恢复阈值 58 是最脆弱的参数

一次性回补的恢复阈值扫描（卖出阈值 25）：45→11.10%、50→11.06%、55→**12.54%**、58→12.28%、60→12.44%、65→**10.06%**、70→11.22%。走势不单调，相邻 5 个点能差 2.5pp。原因是一次性回补把整个资金池押在**某一天**，回补日差几周、成本差 5–10%。"58"这种非整数也是被调出来的典型特征。

### 3.5 卖出阈值 25 实际上不起作用

卖出阈值取 15、20、25 时，结果**完全相同**：三次触发时 S 都在 4.7–11.9，远低于 25。真正决定卖出时点的是均线。这意味着：(a) 25 没有被检验过；(b) 规则书说的"估值 + 趋势双确认"，在历史上其实是"S 极低 + 趋势"，样本里没有 S 在 15–25 之间触发的情形。

### 3.6 口径细节

- 用价格指数会低估约 2pp/年（指数基金净值含分红），但也低估了等待期的机会成本。全收益口径下 Plan C 的优势基本不变（14.37% vs 10.01%）。
- 赎回费 0.5% 对持有超过 1–2 年的份额偏保守（多数场外指数基金持有满 1 年后降到 0.25% 或 0），影响很小。

## 4. 修改建议

1. **第一优先：补齐 2005-04 ～ 2011-09 的 PE-TTM、PB、股息率、10 年国债收益率和收盘价**（中证指数官网、理杏仁、乐咕乐股、中债都有），追加到 `data/` 后重跑。2007–2008 是你从未调过参的样本外区间，也是对"S<25 + 趋势破坏"最好的检验。
2. **参数冻结后，只用样本外数据评价**：Plan C 的所有参数都是在 2013–2026 上选出来的，这段数据已经不能再用来验证它。有了 2005–2013 的数据后，用它做唯一一次检验，不要再回头调参。
3. **把全有全无改成分档**：3 个样本支撑不了"一天卖 100%"这样的二元决策。分档卖出能让单次判断失误的代价减半甚至更少。
4. **均线改成多窗口集成**，不再挑选窗口组。
5. **回补改成分批**，不依赖单一阈值和单一日期；阈值取整数。
6. **等待期继续按公式定投**：S>30 时公式本来就会买。这样少一个状态，也避免 S 在 30–58 之间时白白停投。
7. **业绩基准**：以后汇报时，把"同公式永不清仓"一起列出来，择时部分的贡献要单独看。

## 5. 修改后的策略：Plan D

完整规则见 `PlanD_rulebook.md`。设计原则：**规则在回测之前写定，参数取整数，跑完不再调。**

| | Plan C | Plan D |
|---|---|---|
| 估值分 S、定投公式 | 不变 | 不变 |
| 趋势 | MA40/80/160，U≤1/3 | MA 20/40/60/80/120/160/200/250 八线集成 U8 |
| 卖出 | S<25 且 U≤1/3 → 100% 清仓 | S<25 时，目标卖出比例 = ⌊(1−U8)×4⌋/4（0/25/50/75/100%），只减不加 |
| 回补 | S>58 一次性回补 | S>50 起，资金池分 120 个交易日等额回补 |
| 等待期定投 | 停止 | 照常按公式买 |

### 结果（价格指数口径，2013-11 起）

| | XIRR | 最大回撤 | Calmar | 邻域 XIRR 最差 / P10 / 中位 / P90 / 最好 | 邻域 MDD 最差 |
|---|---|---|---|---|---|
| Plan C | 12.28% | -31.3% | 0.41 | 7.69 / 8.25 / 10.41 / 12.50 / 14.05 | -46.1% |
| **Plan D** | **10.25%** | **-30.0%** | 0.35 | **9.39 / 9.66 / 10.35 / 11.72 / 12.26** | **-37.2%** |
| 永不清仓 | 7.85% | -46.1% | 0.16 | — | — |

（全收益净值口径：Plan C 14.37%，Plan D 12.19%）

**怎么读这张表**：
- **Plan D 的点估计低 2pp，这在预期之内**。Plan C 的 12.28% 是从邻域里挑出来的（第 86 百分位）；Plan D 的 10.25% 接近它自己邻域的中位数（10.35%）。两者邻域中位几乎相同（10.41 vs 10.35），说明**样本外的期望收益大致相当**。
- **Plan D 的邻域窄得多**：最差 9.39% vs 7.69%，P10 9.66% vs 8.25%，最差回撤 -37% vs -46%。参数选错时代价更小，这正是防过拟合要的效果。
- **单参数扰动基本是平的**：卖出区间 15–35 → 10.48–9.57%；恢复阈值 40–60 → 10.25–10.35%；回补天数 20–500 → 10.01–10.34–9.65%。
- **对 2015 单一事件的依赖从 +2.22pp 降到 +0.91pp**。2020–2026 子区间 Plan D 8.90% vs C 8.97%，持平，回撤更低（-29.5% vs -31.3%）。
- 代价：交易更频繁（10 次部分卖出 vs 3 次清仓），在牛市尾段会更早开始减仓（例如 2015-02、2017-04 先卖 25%）。

### 诚实的局限

- §3.1 的问题对 Plan D **同样存在**：如果补齐 2005 年起的数据后 S 在这些位置不再低于 25，Plan D 也不会卖出，退化成"估值加权定投"（XIRR 约 7.85%，仍比等额定投高约 2.8pp）。这一部分是稳健的。
- Plan D 的设计参考了本次在 2013–2026 数据上的诊断结果，严格说它也不是完全样本外的。**真正的检验只能来自 2005–2013 的数据，或 2026-10 之后的实盘。**

*历史回测不代表未来，不构成投资建议。*

## 附录 A：百分位口径对照——扩张窗口 vs 滚动窗口（N=3/5/7）

> 脚本 `window_study.py`，原始输出 `results_window_study.txt`。
> 扩张窗口：t 日百分位 = 当日值在"数据起点 ~ t"中的排名，预热 5 年（2016-09-30 起交易）。
> 滚动窗口：只用 [t−N 年, t]，预热 N 年以保证窗口满长度（3 年 → 2014-09，5 年 → 2016-09，7 年 → 2018-10）。

**先说明一个事实**：数据只有 15 年，原规则的"15 年滚动"其实**一直就是扩张窗口**。两者的 S 相关系数是 1.00，在共同区间内结果完全一样；区别只在原规则 2 年就开始交易，这里要求预热 5 年。

### A.1 共同起点 2018-10-08 起的比较（口径之间可以直接比）

| 口径 | Plan C XIRR / MDD | Plan D XIRR / MDD | 永不清仓 XIRR / MDD |
|---|---|---|---|
| 扩张窗口（预热5年） | 8.76% / -31.3% | 8.58% / -29.9% | 7.92% / -41.6% |
| 滚动 3 年 | 7.58% / -26.6% | 8.16% / -27.2% | 6.90% / -41.6% |
| 滚动 5 年 | 9.57% / -26.6% | 8.64% / -29.1% | 7.15% / -41.6% |
| 滚动 7 年 | 8.38% / -32.5% | 8.19% / -31.6% | 7.79% / -41.6% |
| **口径间极差** | **2.0pp** | **0.5pp** | 1.0pp |

- **所有口径下，两种择时方案都跑赢了永不清仓**（+0.4 到 +2.4pp），回撤都从 -42% 降到了 -27% 到 -32%。可以说"贵 + 趋势破坏时减仓"这个思路对口径不敏感。
- **具体收益多少，取决于选哪种口径**：Plan C 在 4 种口径间相差 2.0pp，Plan D 只差 0.5pp。这和正文 §5 的结论一致，分档 + 集成的设计对口径选择也更稳健。
- 从各自最早可交易日起算的结果见 `results_window_study.txt` §2。各口径起点不同，不能横向比较，所以正文用的是共同起点。

### A.2 清仓事件随口径变化

| 口径 | Plan C 清仓日（S） |
|---|---|
| 扩张窗口 | 2018-02-08（12）、2021-03-09（11） |
| 滚动 3 年 | 2015-06-29（6）、2020-11-02（24）、**2025-11-25（13）** |
| 滚动 5 年 | 2018-02-08（12）、2020-11-02（25）、**2026-07-22（23）** |
| 滚动 7 年 | 2021-03-09（12） |

2021 年初那个顶在 4 种口径下都识别出来了（2020-11 或 2021-03），这是最可信的一次信号。2018 年那次只在扩张窗口和 5 年窗口下出现。

### A.3 你担心的"长期低估时买不够"：一半对，一半反过来

各口径在三段区间里的累计定投额（元）：

| 口径 | 2018-10 ~ 2019-03 | 2022-04 ~ 2024-09 | 2025-01 ~ 2026-09 |
|---|---|---|---|
| 扩张窗口 | 8,550 | 71,321 | **22,506** |
| 滚动 3 年 | 20,439 | 96,478 | **8,614** |
| 滚动 5 年 | 10,491 | 95,609 | 15,409 |
| 滚动 7 年 | 8,248 | 104,231 | 19,641 |

- **你的担心应验在了 2025–26 年。** 2022–24 年连续三年低估之后，滚动 3 年窗口里全是低估值，于是把 2025 年的估值看成"中等甚至偏贵"，这期间只买了 8,614 元，扩张窗口买了 22,506 元。更严重的是，它在 **2025-11-25 PE≈14.0、PB≈1.45 时判定 S≈10（极贵）并清仓**，可这个估值放在 2011 年以来的历史里明显偏低，是典型的误报。按 3 年口径，截至 2026-09-30 仍处于空仓等待状态（S=41，还没到 58）。滚动 5 年也在 2026-07 触发了一次类似的清仓。
- **在 2022–24 年却反过来了。** 扩张窗口里包含 2012–2014 年的极低估值，所以 2022–24 年在它看来"没那么便宜"，买得反而最少（71k，滚动窗口是 96–104k）。也就是说，扩张窗口也会少买，原因是早期出现过更便宜的时候。

### A.4 结论与建议

1. **主口径用扩张窗口，预热 5 年**：没有未来信息，没有 N 要选，长期下来也最稳定（日均波动 1.68，最低）。
2. **滚动窗口只做对照，并排除 N=3**：3 年窗口太短，会把估值中枢的正常回归当成"极贵"（2025-11 的误报），S 低于 25 的时间占 30%，处于停投区间的时间占 36%，都是各口径里最高的。5 年和 7 年可以用作对照。
3. **把"多口径一致"作为清仓的附加条件**，这是一种不增加可调参数的稳健化做法：只有当扩张窗口和滚动 5 年、滚动 7 年**都**给出 S<25 时，才执行卖出。历史上这只会保留 2021 年初那一次（4 种口径都识别出来的那个顶），能过滤掉 2025-11、2026-07 这样只在单一口径下出现的信号。代价是，在只有扩张窗口给出信号的年份（比如 2018），这条规则就不会卖出。
4. 回测年限仍然是最大的限制：要让滚动 7 年口径从 2013 年就能用，需要 2006 年起的数据。补齐 2005–2011 年数据的建议仍然有效。

### B.3 结论

1. **年度更新和日度更新几乎没有差别**（XIRR 差 ≤0.05pp，清仓和回补日期相同或只差 2 天），但年度更新的 S 更平稳（日均波动 1.51 vs 1.68）。实盘中一年只需更新一次参照集，操作更简单，**可以把它作为主口径**。
2. **滚动 10 年和扩张窗口几乎重合**：数据只有 15 年，10 年窗口在 2021 年后与扩张窗口相差无几（S 都约 70，2021-12-21 同一天清仓）。它要在数据更长时才显出区别，现在单独列出的意义不大。
3. **滚动 5 年的历史收益最高（2018 起 9.57%，2021 起 11.33%）。但这不是选它的理由**：它的超额主要来自 2020-11 那次提前清仓，以及 2022–24 年买得更多；而它在 2026-07-22 发出的清仓信号（S=23）是其他口径都没有的。截至 2026-09-30，按滚动 5 年 Plan C 仍处于空仓等待状态（S=52.2，还没到 58），其他口径都在正常定投（S 在 64–71 之间）。这次清仓对不对，要看后市才知道，现在不能算作它的优点。
4. **择时的增益在所有口径下都存在，但幅度不稳定**：2018 起相对永不清仓 +0.6 到 +2.4pp。2021-09 起的 5 年里，扩张、7 年和 10 年口径下的增益**几乎为 0**，只是把回撤从 -34% 降到 -27%。所以在近 5 年里，择时实际提供的是回撤保护，收益增强有限。
5. **Plan D 在不同口径之间仍然是最稳的**：2018 起各口径间的极差，Plan D 是 0.45pp，Plan C 是 1.2pp。

**主口径建议**：扩张窗口·年度更新、预热 5 年，用滚动 7 年做对照。附录 A 提出的"多口径都给出 S<25 才清仓"仍然适用，滚动 5 年的单独信号（如 2026-07）不执行。

# 沪深300估值百分位动态仓位策略 · Plan D 规则书

> 版本：v1.0（规则冻结）　｜　制定日期：2026-10-09　｜　由 Plan C 修改而来
> 设计原则：规则先于回测写定；参数一律取整数；分档决策代替全有全无；冻结后不因回看历史而调整
> 本金口径、费用、成交时点与 Plan C 相同：真实资金流；申购 0.12%、赎回 0.5%；T-1 收盘信号 → T 日收盘净值成交

## 一、策略一句话

**日常按估值分 S 定投（越便宜买越多）；估值极贵（S<25）时，按八条均线中跌破的比例分档减仓（每档 25%）；S 回到 50 以上后，资金池用半年时间分批买回。**

## 二、指标

### 2.1 估值分 S（与 Plan C 相同）
```
ERP = 100/PE-TTM − 10年期国债收益率
S = [ (100 − PB百分位) + 股息率百分位 + ERP百分位 ] / 3
```
百分位：过去 15 个日历年滚动窗口，最少 504 个样本（**建议数据至少从 2005 年开始，否则早期百分位失真，见 REPORT §3.1**）。

### 2.2 集成趋势分 U8（替代 Plan C 的三均线 U）
```
U8 = [ Σ_k I(P > MA_k) ] / 8 ,  k ∈ {20, 40, 60, 80, 120, 160, 200, 250}
```
覆盖约 1 个月到 1 年的全部常用窗口，等权，不挑选窗口。

## 三、交易规则（每日按序执行，用 T-1 的 S 与 U8，T 日收盘成交）

### 3.1 分档减仓（最高优先级）
当 S < 25 时：
```
目标累计卖出比例 L* = floor( (1 − U8) × 4 ) / 4      ∈ {0, 25%, 50%, 75%, 100%}
```
- 若 L* 高于当前已卖出比例 L，则卖出现有持仓的 (L* − L)/(1 − L)，令 L = L*；卖出所得扣 0.5% 赎回费后进入资金池
- **只减不加**：在回补触发前，即使 U8 回升，也不买回已卖出部分
- 例：八条均线跌破 4 条（U8=0.5）→ 累计卖出 50%；跌破 6 条以上 → 累计卖出 75% 及以上

### 3.2 回补
- 当 S > 50 且资金池有余额时，L 归零，**资金池分 120 个交易日等额买回**（扣 0.12% 申购费）
- 回补期间如再次触发 3.1，停止回补，剩余资金留在资金池

### 3.3 定投（任何状态下都执行，卖出当日除外）
```
x = clip( (S − 30) / 70 , 0 , 1 )
当日额度 = 250 × x^2.5
```
- 额度即当日外部入金，挂账满 10 元成交，不用即作废

## 四、参数一览（冻结）

| 参数 | 取值 | 为什么这样取 |
|---|---|---|
| 估值卖出区 | S < 25 | 沿用；邻域 15–35 的 XIRR 都在 9.6–10.5% |
| 趋势 | 8 线集成，按 25% 分档 | 不押注单一窗口 |
| 恢复阈值 | S > 50 | 估值中性点，取整；邻域 40–60 的 XIRR 都在 10.25–10.35% |
| 回补期 | 120 交易日 | 约半年；邻域 60–250 天的 XIRR 都在 10.1–10.3% |
| 定投 | s0=30、指数 2.5、上限 250 | 沿用；网格平滑 |

## 六、每日操作清单
1. 收盘后更新 PE-TTM、PB、股息率、10Y 收益率 → 计算 S
2. 计算 8 条均线 → U8
3. S<25？是 → 计算 L*，若 L* > L 则按差额卖出
4. 资金池有钱且 S>50？是 → 启动或继续 120 日分批回补
5. 按公式定投（满 10 元成交）
6. 记录持仓、资金池、已卖出比例 L、回补剩余天数

*历史回测不代表未来，不构成投资建议。*

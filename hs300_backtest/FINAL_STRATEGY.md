# 沪深300 估值定投 · 最终策略（v2.0，规则冻结）

> 制定日期：2026-10-09　｜　依据：扩张窗口 + 滚动窗口（3/5/7/10 年）全部对照回测（REPORT 附录 A、B，`final_strategy.py`）
> 本质：**Plan D 规则 + 扩张窗口·日度更新的百分位口径**

## 一、最终规则

### 1. 估值分 S（主口径：扩张窗口·日度更新，预热 5 年）
```
ERP = 100/PE-TTM − 10年期国债收益率
t 日百分位 = 当日值在「数据起点 ~ t 日」全部数据中的排名（0~100）
S = [ (100 − PB百分位) + 股息率百分位 + ERP百分位 ] / 3
```
- 数据起点满 5 年才开始交易（本数据包：2011-09-30 起 → 2016-09-30 开始）
- 不设窗口长度上限：数据越多越稳，不需要选 N

### 2. 趋势分 U8
```
U8 = 收盘价站上 MA20/40/60/80/120/160/200/250 的条数 / 8
```

### 3. 每日规则（T−1 收盘信号，T 日收盘净值成交）

| 顺序 | 条件 | 动作 |
|---|---|---|
| ① 减仓 | S < 25 | 目标累计卖出比例 L* = ⌊(1 − U8) × 4⌋ / 4（0/25/50/75/100%）。L* 高于已卖出比例 L 时卖出差额，只减不加 |
| ② 回补 | 资金池有余额且 S > 50 | L 归零，资金池分 120 个交易日等额买回；回补期间再次触发①则暂停 |
| ③ 定投 | 每天（卖出当日除外） | 额度 = 250 × clip((S−30)/70, 0, 1)^2.5 元，满 10 元成交，不用即作废 |

### 4. 参数表（全部取整，冻结）

| 参数 | 值 |
|---|---|
| 百分位口径 | 扩张窗口、日度更新、预热 5 年 |
| 减仓区 | S < 25 |
| 减仓档位 | 25% 一档，由 8 线集成 U8 决定 |
| 回补阈值 / 回补期 | S > 50 / 120 交易日 |
| 定投 | 起投点 S=30，指数 2.5，日上限 250 元，最小成交 10 元 |
| 费用 | 申购 0.12%，赎回 0.5% |

### 5. 滚动窗口的用途：只观察，不交易
每日同时计算滚动 7 年口径的 S，**仅作参考**。两者差距超过 20 分时，在交易记录里标注，但不改变操作。

## 二、为什么是这个版本（三项回测结论）

1. **百分位口径：用扩张窗口，不用滚动窗口。** 滚动 3 年和 5 年会把"长期低估"当成常态：滚动 3 年在 2025-11-25（PE≈14、PB≈1.45）、滚动 5 年在 2026-07-22，都发出了"极贵"的清仓信号，扩张窗口没有。滚动 10 年在现有数据下和扩张窗口几乎重合。扩张窗口不需要选 N，S 的日均波动也最小。
2. **规则：用 Plan D，不用 Plan C。** 换不同口径时，Plan D 的 XIRR 极差是 0.45pp，Plan C 是 1.2pp；参数邻域里，Plan D 的最差结果也明显好于 Plan C。Plan C 在扩张口径下的点估计略高（8.68% vs 8.47%），但它的参数是在同一段数据上挑出来的。
3. **"多口径都确认才卖"：检验后不采用。** 在 Plan D 上加一条"滚动 7 年也给出 S<25 才卖"，结果 XIRR 从 8.47% 降到 8.31%，回撤从 -29.9% 加深到 -31.9%。原因是扩张口径本来就不会发出 2025-11、2026-07 那样的误报，确认条件没有过滤掉任何坏信号，反而让 2021-07 那次正确的减仓没有执行。这是我上一轮的建议，回测证明它没有用，因此撤回。

## 四、当前状态（2026-09-30 收盘）

- S = **68.5**（PB 分位 32.1，股息率分位 69.1，ERP 分位 68.6），属于偏便宜区域
- U8 = 0（收盘 6548 点，低于全部 8 条均线），但 S 远高于 25，**不触发减仓**
- 不在等待期，资金池为空
- **10-08 定投额度 = 250 × ((68.5−30)/70)^2.5 ≈ 56 元**

## 五、预期与局限

- **合理预期**：XIRR 大约 8–9%（价格指数）或 10–11%（含分红），最大回撤约 -30%。择时的主要作用是**降低回撤**（-42% → -30%），收益增强只有约 0.7pp。
- 回测只有 10 年，减仓事件只有 2 轮（2017–18、2020–21）。2005–2015 年的数据补齐后，**只用那段数据做一次检验，不再调参**。
- 收益数字基于价格指数；实际场外基金净值含分红，以全收益口径那一行为准。

*历史回测不代表未来，不构成投资建议。*

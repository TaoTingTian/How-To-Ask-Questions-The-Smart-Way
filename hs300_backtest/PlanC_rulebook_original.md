# 沪深300估值百分位动态仓位策略 · Plan C 完整规则书

> 版本：v1.0（规则冻结）　｜　制定日期：2026-10-08
> 结构：方案B骨架 + 多窗口趋势确认（MA40/80/160 等权U，U≤1/3 即三条中破两条才确认趋势破坏）
> 本金口径：**真实资金流**——每日外部入金=当日公式买入额，额度不用即作废、不积累；资金池为卖出回收款，不计新增本金
> 回测区间：2013-11-07 ～ 2026-09-30（S值首个有效日2013-11-07）
> 费用：申购0.12%、赎回0.5%；信号T-1收盘 → T日收盘（场外净值）成交

---

## 一、策略一句话

**日常按估值分S定投（越便宜买越多）；当估值极度昂贵（S<25）且价格同时跌破40/80/160日三条均线（短、中、长周期趋势全部破坏）时清仓入资金池；待S>58时资金池一次性回补并恢复定投。**

与方案B的唯一区别：趋势确认从"跌破MA60单均线"改为"MA40/80/160三均线等权U≤1/3（三条中至少两条跌破，多数确认）"。

## 二、为什么这样改（与方案B的取舍）

方案B的MA60在参数邻域扫描中是孤峰（MA50→Calmar 0.53、MA60→0.78、MA70→0.42），而全部清仓决策只有3个历史样本，单一窗口的"最优"不可严格识别。Plan C用三条均线（约2个月/4个月/8个月）等权组合分散窗口选择风险：

- 敏感性扫描（XIRR%）：

| 窗口组 \ U阈值 | ≤0（全破） | ≤1/3 | ≤2/3 |
|---|---|---|---|
| 短 40/80/160 | 10.97 | 11.59 | 8.70 |
| 中 60/120/240 | 9.06 | 10.85 | 12.20（≈MA60） |
| 长 80/160/320 | 8.75 | 10.97 | 11.59 |

- **U≤1/3行跨窗口组为11.59/10.85/10.97，是全部9格中最平稳的一行**（波动仅0.7pp）；选择40/80/160+U≤1/3是"用约0.6pp的历史XIRR换参数稳健性"的主动决策，不是历史最优点的挑选（MA60尖峰12.20%的邻域左右塌陷，不可复现性高）
- 代价是确定的：离场更晚，历史回撤更深（见第五节）

## 三、指标定义

### 3.1 估值分 S（与方案B完全一致）

```
ERP = 100/PE-TTM − 10年期国债收益率
S = [ (100 − PB百分位) + 股息率百分位 + ERP百分位 ] / 3
```

- 百分位：过去15个日历年滚动窗口，最少504个有效样本
- S越高越便宜；每日收盘后计算

### 3.2 趋势分 U（本方案特有）

```
U = [ I(P>MA40) + I(P>MA80) + I(P>MA160) ] / 3
```

- P为沪深300收盘价；MA_k为k个交易日的简单移动平均
- U只取 0、1/3、2/3、1 四档
- **U≤1/3（三条均线中至少两条未站上）才判定"趋势破坏"**；等于均线不算站上。选择"多数确认"是"太早离场"与"太晚离场"之间的结构性中点，历史回测不反对（跨窗口组XIRR稳定在10.85~11.59%平台），并非因其为历史最高点而挑选

## 四、交易规则（每日按序执行）

用 **T-1日** 的S与U决策，T日收盘成交。

### 4.1 清仓（最高优先级）

**触发条件（同时满足）：**
1. S < 25（极度昂贵）
2. U ≤ 1/3（收盘低于MA40、MA80、MA160中的至少两条）

**动作：** 卖出全部持仓，扣除0.5%赎回费后进入资金池；进入等待状态；当日不再定投。

### 4.2 等待期

- 不定投、不试探、无操作
- **恢复条件：S > 58** → 资金池全部余额一次性回补（扣除0.12%申购费），恢复正常定投

### 4.3 正常定投（非等待状态且未触发清仓）

```
x = clip( (S − 30) / 70 , 0 , 1 )
当日买入金额 = 250 × x^2.5   （S>30时；S≤30为0元）
```

- **当日买入额 = 当日真实外部入金**，用不完的额度作废、不积累
- 挂账满10元成交；买入扣0.12%费用

## 七、与方案B的选择建议

- **要历史最优数字** → 方案B（XIRR 12.20%），接受MA60孤峰的参数脆弱性
- **要参数稳健性** → Plan C（XIRR 11.59%），趋势判断不押注单一窗口
- 两者差距约0.6pp XIRR，小于市场一年的随机波动；**选定后冻结，不因回看历史而切换**

## 八、每周/每日操作清单

1. 收盘后更新：PE-TTM、PB、股息率、10Y国债收益率 → 计算三个百分位 → S
2. 计算MA40、MA80、MA160 → U
3. 等待中：S>58？是→资金池全投+恢复定投；否→无操作
4. 正常中：S<25 且 U≤1/3（至少两条均线跌破）？是→全部赎回；否→按公式买入（满10元成交）
5. 记录持仓、资金池、挂账三项余额

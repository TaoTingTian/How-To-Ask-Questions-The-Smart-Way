# 沪深300「风险溢价定仓」策略（ERP-Merton）

## 一句话思路

不去问"现在的估值在历史上排第几"（那样的话，用哪段历史、阈值定多少，都是要选的参数），而是问：

> **现在买股票比买国债每年多赚多少？这份多出来的钱，值得承担多大的波动？**

指数下跌时，盈利收益率 E/P 会上升，股票相对国债的超额补偿（ERP）随之变大，仓位就自动加上去；泡沫期正好反过来。这就是均值回归。和百分位法不同的是，它的"锚"是**国债收益率加上风险补偿**这个经济量，不依赖某一段历史分布。

## 规则（运行回测前就已写死）

```
w = clip( ERP / (γ · σ²), 0, 1 )

ERP = 1/PE_TTM − 10年国债收益率         （当天已知）
σ   = 截至当天的扩展窗口年化波动率      （只用过去数据）
γ   = 2                                （教科书中"中等风险厌恶"，不从本数据估计）
```

- 每月最后一个交易日计算，**下一个交易日**收盘执行。
- 目标仓位和当前仓位相差超过 10% 才调仓。单边成本 0.1%。
- 不持有股票的部分放国债（按票息近似）。

这个公式就是 Merton 最优仓位公式，**没有任何参数是从回测里拟合出来的**，也没有阈值和百分位。

## 结果（2012-11 ~ 2026-09，数据只到 2026-09-30）

| | 年化 | 波动 | 夏普 | 最大回撤 | 卡玛 |
|---|---|---|---|---|---|
| **ERP-Merton** | **10.0%** | 10.9% | **0.92** | **−14.9%** | **0.67** |
| 买入持有（含股息） | 9.8% | 21.4% | 0.46 | −45.3% | 0.22 |
| 静态 52% 股 + 债（相同平均仓位） | 7.1% | 11.1% | 0.63 | −25.2% | 0.28 |

总共只调仓 30 次，大约每 5 个月一次。

**关键比较对象是第三行。** 策略平均只拿了 52% 的股票，如果只和满仓的买入持有比，回撤小可能仅仅因为仓位低。和同样仓位的静态组合比，每年多出约 2.9%，这部分才是择时本身的贡献。

## 过拟合检验

| 检验 | 结果 |
|---|---|
| 参数网格 240 组（γ 1~4 × σ 4 种 × 调仓带宽 0~20% × 执行滞后 1/5/21 天） | **96%** 的组合跑赢同仓位静态组合，超额中位数 1.6%/年，最差的一组 −0.09%；**100%** 的组合回撤更小 |
| 执行滞后到 21 天（一个月后才执行） | 超额几乎不变（1.8%），说明不依赖精确择点 |
| 三个子区间（2012-16 / 2017-20 / 2021-26） | 每一段都跑赢同仓位静态组合 |
| 滚动 3 年窗口 | 100% 跑赢同仓位静态组合；对买入持有只有 49% 跑赢 |
| 安慰剂：仓位序列随机平移 300 次 | 随机超额中位数 −0.2%，没有一次达到真实值（p < 0.01） |

见 `robustness.png`：参数网格的分布（红色）整体落在 0 的右边，安慰剂的分布（灰色）以 0 为中心。

## 必须说清楚的局限

1. **主方案在网格中排位偏上**（2.9%，网格中位数是 1.6%）。实际预期应该按 **1~2%/年的择时超额**来估，不要按 2.9%。
2. **它跑不赢牛市里的满仓。** 2017-2020 年策略年化 11%，买入持有是 16.8%。它的价值在于用一半的波动拿到和满仓差不多的收益，不能指望它收益翻倍。
3. 只有约 14 年的数据，大约 2.5 个牛熊周期。另外，γ=2 虽然取自理论，但我是知道这段历史的人，无法完全排除"事后知道"的影响。
4. 股息按股息率/252 近似计入，现金腿按 10 年国债票息近似计入（没有算债券价格波动）。由于静态基准用了同样的假设，这部分对"择时超额"的影响会相互抵消。
5. E/P 直接当作预期收益，在银行股权重高、盈利质量下降的时期可能高估实际回报。

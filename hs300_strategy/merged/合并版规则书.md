# 沪深300估值定投 + 分批趋势卖出 · 合并版 v2.0

> 基于：Plan C v1.0（2026-10-08 冻结）
> 状态：**已按事前标准通过验证（2026-10-09，容忍度 0.5pp）**，结果见第七节。采用后冻结。
> 改进目标：**稳健性**，即结果对参数和少数历史样本的依赖更小，不是追求更高的回测数字。

---

## 一、只改一处

| | Plan C v1.0 | 合并版 v2.0 |
|---|---|---|
| 买入 | S 定投，250 × x^2.5 | **不变** |
| 卖出 | S<25 且 U≤1/3 → **一次性清仓** | S<25 时，持仓按 U 的档位**分批减、只减不加** |
| 回补 | S>58 资金池一次性回补 | **不变** |
| U 阈值参数 | 需要选（0 / 1/3 / 2/3） | **取消**，三档都用 |
| 新增参数 | – | **无** |

## 二、为什么这样改更稳健

**1. 少了一个最敏感的参数。** 你自己的扫描表里，XIRR 对 U 阈值最敏感：同一组均线下，只换 U 阈值，XIRR 就相差 2.8~3.1pp（例如中组 9.06~12.20）。合并版把三档都用上，各管三分之一仓位，不需要再选阈值。

**2. 把 3 次"全卖或全不卖"的单次判断，拆成分步执行。** 三次清仓是全部的历史样本，每次都是 100% 押在一个时点上。分批之后，任何一次判断失误只影响三分之一仓位。

**3. 根据你的扫描表，可以粗略预估效果。** 分批相当于把三个 U 阈值的结果平均：

| 均线组 | U≤0 | U≤1/3 | U≤2/3 | **三档平均（≈合并版）** |
|---|---|---|---|---|
| 短 40/80/160 | 10.97 | 11.59 | 8.70 | **10.42** |
| 中 60/120/240 | 9.06 | 10.85 | 12.20 | **10.70** |
| 长 80/160/320 | 8.75 | 10.97 | 11.59 | **10.44** |

- 跨均线组的波动：从 Plan C 那一行的 0.74pp **降到约 0.28pp**
- 代价：XIRR 预计比 Plan C 的 11.59% **低约 1pp**

这只是忽略了路径差异的粗算，真实结果以回测为准。但方向很清楚：**用约 1pp 收益换更低的参数敏感性。** 这和你当初从方案B换到 Plan C 的取舍性质一样（当时用 0.6pp 换稳健性），只是幅度更大。值不值，需要你在跑数据**之前**决定（见第五节）。

## 三、指标定义（与 v1.0 相同）

```
ERP = 100/PE-TTM − 10年期国债收益率
S   = [ (100 − PB百分位) + 股息率百分位 + ERP百分位 ] / 3      （15 个日历年滚动，≥504 个样本）
U   = [ I(P>MA40) + I(P>MA80) + I(P>MA160) ] / 3                （只取 0、1/3、2/3、1 四档）
```

## 四、交易规则（每日按序执行；T-1 日信号，T 日收盘成交）

维护一个状态变量 **R（已到达的最低档位）**，初始为 1。

### 4.1 回补（先判断）
若 S > 58 且 R < 1（有过减仓）：资金池全部余额一次性买入（0.12% 申购费），R 重置为 1，恢复正常定投。

### 4.2 分批卖出
若 S < 25 且 U < R：
```
卖出比例 = 1 − U / R      （按当前持有份额计）
R ← U
```

| U 从 → 到 | 卖出当前持仓 | 累计已卖（相对初始仓位）|
|---|---|---|
| 1 → 2/3 | 1/3 | 1/3 |
| 2/3 → 1/3 | 1/2 | 2/3 |
| 1/3 → 0 | 全部 | 全部 |
| 1 → 1/3（一步到位）| 2/3 | 2/3 |

- 卖出款扣 0.5% 赎回费后进入资金池
- **只减不加**：U 回升不买回；S 回到 25 以上也不买回。只有 S>58 才回补
- R 降到 0 = 全部清仓，进入等待期，与 v1.0 相同：不定投，挂账转入资金池

### 4.3 正常定投（与 v1.0 相同）
```
x = clip((S − 30) / 70, 0, 1)
当日买入额 = 250 × x^2.5      （= 当日外部入金，不用即作废；挂账满 10 元成交；0.12% 费用）
```
部分减仓后（0 < R < 1）定投照常进行，因为它本来就只在 S>30 时买入。

## 五、采用前的检验流程（顺序不能颠倒）

**第 0 步：先定好容忍度，写在这里再跑数据。**
> 我愿意为更低的参数敏感性，接受 XIRR 中位数最多下降 **0.5pp**（采用默认值，运行前未改动）。（按上面的粗算，合并版大概率要 1pp 左右才能通过）

**第 1 步：复现检查。** 脚本用 v1.0 参数必须复现规则书数字：累计本金 161,694 元，三次清仓日 2015-06-29、2018-02-08、2021-03-09（允许 ±1 个交易日）。复现不了，说明数据或口径不一致，后面的对比都不可信。

**第 2 步：参数邻域对比。** 卖出线 20/25/30 × 回补线 53/58/63 × 三组均线，共 27 格。如果提供原始 PE/PB/股息率/国债数据，再加估值窗口 10/15/20 年，共 81 格。v1.0 和 v2.0 在每一格上都跑。

**第 3 步：按事前标准判定。** 以下三条**全部满足**才采纳 v2.0：
1. v2.0 的 XIRR 跨参数四分位距小于 v1.0（U≤1/3）
2. v2.0 的 XIRR 中位数下降不超过第 0 步写下的容忍度
3. v2.0 的最大回撤中位数恶化不超过 2pp

**第 4 步：安慰剂检验。** 把 U 序列随机平移，打乱趋势信号和行情的对齐，看两个版本的 XIRR 还剩多少。这一步检验趋势确认到底有没有贡献，还是卖出的价值几乎全部来自估值条件本身。

**判定之后不再调整任何参数。** 不通过就继续用 v1.0，同样冻结。

## 六、不改规则、但需要持续盯住的风险

1. **价格序列口径。** 你规则书里的点位（4857 / 4896 / 6477）和沪深300价格指数（4192 / 4012 / 4971）不一致，应该是全收益指数或基金净值。均线要和回测用同一条序列计算；实盘也必须用同一条。
2. **回补线可能长期等不到。** 如果估值中枢持续上移，S 可能很多年都到不了 58，资金池一直闲置。15 年滚动窗口能缓解但不能消除这个问题。建议每年检查一次资金池闲置了多久；如果确实出现，修改规则要走第五节的完整流程，而不是临时决定。
3. **样本量。** 无论 v1.0 还是 v2.0，卖出决策都只有约 3 个历史周期。分批卖出降低了单次判断的代价，但不能凭空增加样本。

## 七、验证结果（2026-10-09，数据 2011-09-30 ～ 2026-09-30）

**复现检查：通过。** 用 v1.0 参数复现规则书：

| 指标 | 规则书 | 脚本 |
|---|---|---|
| 累计本金 | 161,694 | 161,893（+0.12%）|
| 期末价值 | 362,788 | 363,190（+0.11%）|
| TWR 年化 | 12.57% | 12.57% |
| 最大回撤 | −31.8% | −31.8% |
| 三次清仓 / 回补日期及当日 S | 见规则书 | 6 个日期全部一致 |
| XIRR | 11.59% | **12.28%** |

XIRR 是唯一对不上的指标。其余指标全部一致，说明交易和资金流相同，差异只在 XIRR 的计算口径（现金流计时方式）。下面所有对比都用同一个 XIRR 公式，相互之间可比，但绝对值和规则书的 11.59% 不可直接对照。

**默认参数对比：**

| | Plan C v1.0 | 合并版 v2.0 | 只定投不卖出 |
|---|---|---|---|
| XIRR | 12.28% | 11.00% | 7.85% |
| TWR 年化 | 12.57% | 11.10% | 7.40% |
| 最大回撤 | −31.8% | **−28.2%** | −46.1% |
| Calmar | 0.40 | 0.39 | 0.16 |

**参数邻域（81 格：卖出线 × 回补线 × 均线组 × 估值窗口）：**

| | 合并版 v2.0 | Plan C v1.0 |
|---|---|---|
| XIRR 中位数 | 10.60% | 10.98% |
| XIRR 四分位距 | **1.71pp** | 2.19pp |
| 最大回撤中位数 | −30.7% | −31.3% |
| Calmar 中位数 | 0.34 | **0.37** |

- 逐格配对：合并版 XIRR 更高的格子只占 22%（中位数 −0.42pp），但回撤更浅的格子占 74%（中位数浅 1.55pp）
- **Plan C 的默认点位于自身邻域的第 88 百分位**：12.28%，而邻域中位数为 10.98%。冻结的参数刚好落在历史上偏幸运的位置，对未来更现实的预期在 11% 左右。合并版默认点在第 63 百分位，偏离较小
- 安慰剂检验：两个版本把 U 随机错位后，XIRR 都降到 9% 左右，没有一次不差于真实值。说明趋势确认的时机确实有贡献，而不只是估值条件在起作用

**事前判定：三条标准全部满足，采纳 v2.0。**

**代价要说清楚：**
1. 默认点上 XIRR 低 1.28pp，邻域中位数低 0.38pp
2. Calmar 中位数反而略低（0.34 对 0.37）。回撤变浅的幅度，不足以抵消收益的下降
3. 分批卖出会在牛市中段先卖掉 1/3：2015-02、2017-04、2020-09 三次都是 U 刚跌到 2/3 就减仓，之后行情继续上涨。这是"不押注单一时点"必须付出的成本，不是 bug

换来的是：结果对参数选择更不敏感（四分位距缩小约 22%），默认点不依赖"幸运位置"，单次判断失误只影响三分之一仓位。
